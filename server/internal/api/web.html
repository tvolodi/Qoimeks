Подключить приложение

В приложении на телефоне нажмите значок шестерёнки ⚙, затем «Сканировать QR» и наведите камеру на код.

QR с кодом доступа никому не показывайте: по нему можно войти в систему.

Чтобы увидеть данные, введите код доступа: кнопка «Войти» справа вверху.

История загрузок

Отмена загрузки возвращает остатки, которые она изменила. Записи не удаляются: в историю добавляются обратные корректировки, а операции, сделанные после загрузки, сохраняются. Названия и места товаров отмена не меняет.

Настройки

Языковая модель и распознавание речи: сервис, модель и ключ. Ключ хранится на сервере в зашифрованном виде, здесь виден только в закрытой форме и в приложение не передаётся. Раздел открывается только общим кодом доступа. Кнопка «Проверить» делает один недорогой запрос с сохранёнными настройками (или с переменными окружения, если ничего не сохранено).
